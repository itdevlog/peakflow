# SP5A — Интерактивный график и UX-мелочи Mini App

> **Дата:** 2026-09-21
> **Подпроект:** Фаза 5.1 + 5.6
> **Статус:** реализовано (принято)
> **Зависимости:** Фазы 0–4 в main (554 тестов, CI зелёный)
> **Не входит:** pinch/pan, межмесячный диапазон, графические библиотеки/CDN

---

## 1. Цель

Сделать график в Mini App полезнее: переключение вида (линия/столбцы/точки),
быстрый выбор диапазона (неделя/месяц) и информативный тултип (значение, дата,
зона, заметка). Плюс три UX-мелочи из аудита: защита от двойного сохранения заметки,
кэш доступных месяцев (без лишнего запроса при листании) и подсказка «откройте
приложение заново» при истёкшей авторизации.

**Успех:** всё работает на телефоне без библиотек; тултип показывает заметку; листание
месяцев не делает лишний запрос; двойной тап «Сохранить» не создаёт дубль; истёкший
initData даёт понятную подсказку.

---

## 2. Тип графика

- Переключатель «Линия / Столбцы / Точки» в шапке графика (`#chart-controls` в
  `index.html`, внутри `#screen-chart`).
- Состояние — `state.chartType` (`"line"` по умолчанию).
- `drawChart(data, points, type)` рисует:
  - `line` — текущий вид (линия + маркеры);
  - `bars` — столбцы от нижней границы до значения, цвет по зоне;
  - `points` — только маркеры (без соединяющей линии).
- Смена типа перерисовывает из уже загруженных точек (без запроса) и скрывает тултип.

---

## 3. Диапазон (вместо zoom/pan)

- Кнопки «Неделя / Месяц» (по умолчанию «Месяц»), состояние — `state.chartRange`.
- «Неделя» — точки за последние 7 дней, заканчивая последним замером месяца
  (`date >= lastDate - 6 дней`); «Месяц» — все точки месяца.
- Фильтрация на клиенте; навигация ‹/› по месяцам сохраняется; при смене месяца
  диапазон сбрасывается на «Месяц». Жесты не используются.

---

## 4. Тултип

- Тап по canvas (`chartClick`, как сейчас) показывает ближайшую точку:
  `Дата · Утро/Вечер · ПСВ л/мин · N% · 🟢/🟡/🔴 · заметка` (заметка — только если есть).
- Процент: `Math.floor(pef / target_pef * 100)` (как в карточках и на сервере; при
  `target_pef == 0` — не показывать %).
- Зона: из `data.zones` (`green`/`yellow`/`red`) — та же логика, что в остальном клиенте.
- Тултип скрывается при смене типа/диапазона/месяца.

**API:** `GET /api/chart` добавляет в каждую точку `"note": r.get("note") or ""`.

## 5. UX-мелочи (5.6)

1. **busy-guard на «Сохранить заметку»** (`openNote`): на время POST кнопка `#note-save`
   получает `disabled` (и текст «Сохраняем…»); восстанавливается в `finally`. Двойной клик
   не отправляет второй запрос.
2. **Кэш `available_months`**: `loadChart` сохраняет `data.available_months` в `state.months`;
   `shiftMonth` навигирует по `state.months` **без** дополнительного запроса `/api/chart`.
   Если `state.months` пуст (первый вход), допускается один запрос для его заполнения.
3. **Подсказка об истёкшем initData**: `showError(msg)` при `msg === "Нет доступа"`
   показывает баннер `#auth-hint` («Откройте приложение заново из Telegram») вместо общего
   тоста `#error`. Баннер показывается один раз за сессию. Все места уже вызывают
   `showError(e.message)`, поэтому отдельная правка `api()` не нужна.

## 7. Обработка ошибок и краевые случаи

| Ситуация | Поведение |
|----------|-----------|
| Нет точек за месяц | как сейчас: подсказка «В этом месяце замеров нет», `#chart` и `#chart-controls` скрыты |
| Одна точка | «Неделя» и «Месяц» показывают её; линия не рисуется (как сейчас `n >= 2`) |
| Пустая заметка / `null` | `note` = `""`, в тултипе не показывается |
| `target_pef == 0` | процент/зона не показываются, только значение и дата |
| Первый `shiftMonth` без кэша | один запрос для заполнения `state.months`, затем локальная навигация |
| Повторный 403 «Нет доступа» | баннер показывается один раз за сессию |

## 10. Риски и решения

| Риск | Решение |
|------|---------|
| Нет node для проверки JS | статические тесты + ручной прогон, описанный в PR |
| `note` ломает существующие chart-тесты | тесты обращаются к полям, не к точному словарю — безопасно |
| Кэш месяцев устаревает | обновляем `state.months` при каждом `loadChart` |
| Баннер на легитимный 403 (не-родитель) | триггер только при `detail === "Нет доступа"` (авторизация) |
| Столбцы/точки искажают масштаб | общий расчёт осей `yMin/yMax` как сейчас |
