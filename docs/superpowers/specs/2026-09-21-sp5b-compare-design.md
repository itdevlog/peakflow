# SP5B — Сравнение периодов на графике

> **Дата:** 2026-09-21
> **Подпроект:** Фаза 5.2
> **Статус:** дизайн на ревью
> **Зависимости:** Фазы 0–4, SP5A в main (554 теста, CI зелёный)
> **Не входит:** произвольные периоды, квартал, наложение сравнения на обычный график, сравнение утро/вечер

---

## 1. Цель

Показать на одном графике **текущий период vs предыдущий такой же** (неделя/месяц),
свернув замеры в **среднее за день**, чтобы родитель видел динамику «лучше/хуже, чем
раньше» по дням.

**Успех:** переключатель «Сравнить» на экране графика показывает два ряда (текущий и
прошлый) по дням; данные строго по активному ребёнку семьи; нет замеров — график пустой
без ошибок.

---

## 2. Периоды и выравнивание

- Текущий период — `report_pdf.period_bounds(period, today)` (`week` = Пн–Вс, `month` =
  календарный месяц).
- Предыдущий период — `report_pdf.period_bounds(period, current_start - 1 день)`.
- Неделя: обе серии 7 точек; подписи `Пн…Вс`.
- Месяц: серии выравниваются по номеру дня; длина = `max(дней_в_текущем, дней_в_прошлом)`;
  подписи `"1"…"31"`; для прошлого месяца дни за его пределами → `null`.

def daily_average_series(rows: list[dict], dates: list[str]) -> list:

## 4. API `GET /api/chart/compare`

`require_user`; активный ребёнок и семья из `auth`; `active_child_id is None` → `404`;
невалидный `period` → `422`.

Ответ:

```json
{
  "period": "week",
  "labels": ["Пн", "Вт", "Ср", "Чт", "Пт", "Сб", "Вс"],
  "current": [250.0, null, 260.0, 255.0, 262.0, 258.0, 270.0],
  "previous": [240.0, 245.0, null, 250.0, 248.0, 255.0, 252.0],
  "target_pef": 260,
  "zones": {"green": 80, "yellow": 60},
  "title": "16–22.09.2026 vs 09–15.09.2026"
}
```

- `labels` той же длины, что `current`/`previous`.
- Данные — `get_measurements_between(child_id, from, to, family_id)` для каждого периода;
  `report.daily_average_series` сворачивает по дням; выравнивание — по правилам §2.
- `title` — `f"{period_label(period, today)} vs {period_label(period, current_start - 1 день)}"`
  (`report_pdf.period_label`).
- Новых зависимостей нет.

## 5. Фронтенд (`web/static/app.js`, `index.html`)

- Кнопка «Сравнить» (`data-compare`) на экране графика переключает `state.chartCompare`.
- В режиме сравнения: показываем период «Неделя/Месяц» (переиспользуем `data-chart-range`),
  скрываем переключатель типов (`data-chart-type`); запрашиваем `/api/chart/compare`.
- `drawCompare(data)`: два ряда по индексу дня — текущий сплошной `var(--accent)`-цвет,
  прошлый пунктир muted; маркеры; подписи по дням; линия нормы из `target_pef`.
- Тултип по тапу у ближайшего индекса: `День N · текущий: X · прошлый: Y` (с `—` для `null`).
- Выход из режима сравнения возвращает обычный месячный график из уже загруженного
  `state.chartData` (без запроса).

## 6. Обработка ошибок и краевые случаи

| Ситуация | Поведение |
|----------|-----------|
| Нет замеров ни в одном периоде | оба ряда `null`/пусто, подсказка «Нет данных для сравнения» |
| Нет замеров только в прошлом | прошлый ряд пуст, текущий рисуется |
| Месяц/месяц разной длины | выравнивание по дню, лишние дни прошлого → `null` |
| Неделя через границу года/месяца | считается `period_bounds`, подписи Пн–Вс |
| Нет активного ребёнка (веб) | `404` |
| Невалидный период | `422` |
| `target_pef == 0` | линия нормы не рисуется |

## 8. Критерии приёмки

- [ ] «Сравнить» переключает режим; неделя/месяц доступны.
- [ ] Два ряда по дням (текущий/прошлый), подписи дней, линия нормы.
- [ ] Месяц корректно выравнивается при разной длине; пустые дни — разрыв.
- [ ] Тултип показывает значения обоих периодов.
- [ ] Изоляция семьи/ребёнка подтверждена тестом.
- [ ] Пустые данные не дают ошибок; 422/404 соблюдены.
- [ ] `pyflakes` + `compileall` + все тесты зелёные; документация/счётчики обновлены.

## 9. Риски и решения

| Риск | Решение |
|------|---------|
| Разная длина месяцев | выравнивание по номеру дня, `null` для отсутствующих |
| Границы недели/года | единый `report_pdf.period_bounds` |
| Два запроса к БД | по одному `get_measurements_between` на период, в `to_thread` |
| Наложение сравнения на обычный график | отдельный `drawCompare`, переключатель режима |
| Пустой прошлый период | рисуем текущий, прошлый — пропуски |
