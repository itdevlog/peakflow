# SP5E — Корреляция заметок с ПСВ

> **Дата:** 2026-09-21
> **Подпроект:** Фаза 5.5
> **Статус:** дизайн на ревью
> **Зависимости:** Фазы 0–4, SP5A–SP5D в main (579 тестов, CI зелёный)
> **Не входит:** NLP/стемминг сверх корней, ввод тегов, графики по заметкам, причинность

---

## 1. Цель

Показать, как связаны типичные заметки («болел», «спорт», «лекарства»…) со средним ПСВ:
секция «Заметки» на вкладке «Аналитика» с базовым уровнем и отклонением по каждой группе.
Анализ — по всем замерам активного ребёнка семьи.

**Успех:** группы распознаются по корням слов; видно средний ПСВ и отклонение от «обычного»;
данные изолированы; пустые данные не дают ошибок; логика покрыта unit-тестами.

## 3. API `GET /api/analytics` (расширение)

Добавляется поле `notes` (остальные поля не меняются):

```json
{
  "zones": {...}, "weekday": [...], "trend": {...},
  "notes": {
    "baseline": {"avg": 250.0, "count": 40},
    "groups": [
      {"key": "sick", "title": "Болел", "avg": 210.0, "count": 5, "delta": -40.0},
      {"key": "sport", "title": "Спорт", "avg": null, "count": 0, "delta": null}
    ]
  }
}
```

- Считается по `rows` (вся история, уже загруженная эндпоинтом SP5D).

## 4. Mini App — секция «Заметки»

На вкладке «Аналитика» (`loadAnalytics`) добавляется карточка:

- строкой «Обычно: `{avg}` (`{count}`)» (или «Нет данных», если `baseline.avg is None`);
- по каждой группе: название, `avg` (или «—»), число замеров, `delta` с цветом
  (🟢 при `delta >= 0`, 🔴 при `delta < 0`, «—» при `None`);
- пустой `groups` или все пустые → одна подсказка «Нет данных».

## 5. Обработка ошибок и краевые случаи

| Ситуация | Поведение |
|----------|-----------|
| Нет заметок | baseline = среднее по всем, все группы count=0, avg/delta None |
| Все замеры с заметками | baseline.count == 0, delta у групп `None` |
| Заметка пустая/None | не матчится |
| Заметка с несколькими корнями | учитывается в нескольких группах |
| Регистр/русские буквы | сравнение в нижнем регистре, подстрока |
| Нет данных вообще | baseline.avg None, groups с count=0 |

## 7. Критерии приёмки

- [ ] Группы распознаются по корням без учёта регистра; пустая заметка игнорируется.
- [ ] `note_correlation` даёт baseline, avg/count/delta по группам; безопасен при пустых данных.
- [ ] `/api/analytics` отдаёт `notes`; изоляция семьи сохранена.
- [ ] Секция «Заметки» показывает базовый уровень и отклонения с цветом.
- [ ] `pyflakes` + `compileall` + все тесты зелёные; документация/счётчики обновлены.

## 8. Риски и решения

| Риск | Решение |
|------|---------|
| Ложные срабатывания корней | короткие осмысленные корни; легко расширять список |
| Русская морфология | подстрочный поиск корня покрывает формы |
| Мало данных → шум | показываем count рядом с avg, delta без статистических заявлений |
| Заметка в нескольких группах | учитывается в каждой (осознанно) |
