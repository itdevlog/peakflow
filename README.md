# 🫁 Пикфлоуметр — семейный сервис

Telegram-бот **и** Telegram Mini App для отслеживания пиковой скорости выдоха (ПСВ).
Мульти-семейный: у каждой семьи свои родители и один или несколько детей; у родителя —
свой активный ребёнок. Регистрация — самопропускная (создать семью или войти по коду);
данные в `.env` (`CHILD_ID`/`PARENT_IDS`) лишь сидируют семью №1 и остаются fallback'ом.

## Возможности

- 🏠 **Семьи и приглашения** — создать семью или войти по коду (`/start`, deep-link)
- 👨‍👩‍👧 **Несколько детей** — активный ребёнок на каждого родителя (бот и Mini App)
- 🕐 **Авто-утро/вечер** — определяется по времени (< 12 / ≥ 12)
- 📊 **Статус-блок** — сегодня, последний замер, тренд, 🔥 серия дней
- 📥 **Быстрый ввод** — кнопка → число → готово (пошаговые сотни/десятки)
- ✏️ **Исправить последний** — опечатался? одна кнопка
- 📈 **Сводка и неделя vs прошлая** — тренды утро/вечер
- 📊 **График в Mini App** — типы (линия/столбцы/точки), диапазон неделя/месяц,
  тултип со значением, зоной и заметкой, режим «Сравнить» с прошлым периодом
- 🏅 **Геймификация** — серия дней подряд, достижения (7/30/100 дней, 100/500/1000 замеров)
- 📄 **PDF-отчёт врачу** — A4 (график + статистика + таблица), неделя/месяц/квартал
- 📈 **Аналитика** — зоны, средний ПСВ по дням недели, тренд за 14 дней, корреляция заметок
- 📲 **PWA** — установка Mini App на домашний экран и офлайн app-shell
- 🔔 **Напоминания** — 10:00 / 22:00, если замер пропущен (часы на семью)
- 📋 **Недельный отчёт** — воскресенье 21:00, на каждого ребёнка
- 📲 **Уведомления** — родителям семьи при каждом замере
- 🚨 **Красная зона** — мгновенное предупреждение (кроме автора замера)
- 📥 **Экспорт CSV и бэкап** — по периодам; бэкап данных одной семьи
- 🩺 **Метрики** — расширенный `/healthz` и опциональный `GET /metrics` (Prometheus)

## Настройка (.env)

```env
BOT_TOKEN=123456789:AAE...
CHILD_ID=123456789          # сид/fallback ребёнка семьи №1
PARENT_IDS=987654321,111222333  # сид/fallback родителей семьи №1
CHILD_NAME=Маша
TARGET_PEF=260
DB_PATH=peakflow.db
TZ_OFFSET=5

WEBAPP_HOST=127.0.0.1       # доступ к Mini App только через Caddy
WEBAPP_PORT=8080            # 0 = выключить веб-сервер
WEBAPP_URL=                 # публичный HTTPS-URL; пусто = кнопки Mini App нет
METRICS_ENABLED=0           # 1 = включить GET /metrics
METRICS_TOKEN=              # Bearer-токен для /metrics
```

ID узнать через [@userinfobot](https://t.me/userinfobot). Полный список — `.env.example`.

## Запуск

source venv/bin/activate

## Установка на сервер

Быстрая установка с нуля:

```bash
curl -fsSL https://raw.githubusercontent.com/itdevlog/peakflow/main/manage.sh | bash -s -- install
```

Скрипт спросит каталог установки (по умолчанию `/opt/peakflow`),
склонирует репозиторий, поставит Python-окружение и зависимости, интерактивно
настроит `.env` и предложит systemd-сервис.

Управление из каталога установки:

| Команда | Что делает |
|---------|------------|
| `./manage.sh install` | Установка: venv, зависимости, `.env`, systemd |
| `./manage.sh update` | Обновление с GitHub + бэкап + откат при сбое |
| `./manage.sh start` / `stop` / `restart` | Управление ботом |
| `./manage.sh status` | Статус + health-check `/healthz` |
| `./manage.sh logs` | Логи в реальном времени |
| `./manage.sh backup` | Бэкап БД + `.env` (последние 10) |
| `./manage.sh restore` | Восстановление из бэкапа |
| `./manage.sh doctor` | Диагностика конфигурации |
| `./manage.sh caddy` | HTTPS для Mini App (Let's Encrypt) |
| `./manage.sh uninstall` | Остановка и удаление сервиса |

### Веб-версия (Telegram Mini App)

Когда `WEBAPP_URL` задан, бот добавляет кнопку меню «💨 Дневник». Mini App доступен
ребёнку и родителям (проверка подписи Telegram initData, данные старше 24 ч отклоняются)
и имеет вкладки: **Сегодня**, **История**, **График**, **Статистика**, **Аналитика** и
**⚙️ Настройки** (родителям). Родителям доступны PDF-отчёт врачу, экспорт CSV по периодам
и бэкап БД. Несколько ботов на одном сервере: каждый — свой каталог, `WEBAPP_PORT` и
фрагмент Caddy (`--instance`/`RASPISANIE_INSTANCE`).

## Структура

```
peakflow/
├── bot.py           # Логика бота (хендлеры, FSM, планировщик)
├── database.py      # SQLite CRUD + миграции (PRAGMA user_version)
├── config.py        # Настройки и пороги
├── report.py        # Общие хелперы и CSV
├── report_pdf.py    # PDF-отчёты врачу (A4)
├── gamification.py  # Серия дней и достижения
├── analytics.py     # Зоны, дни недели, тренд, корреляция заметок
├── metrics.py       # In-process метрики + Prometheus-рендер
├── web/             # Mini App (FastAPI + static, PWA)
├── test/            # pytest-тесты
├── scripts/         # migration_dry_run.py
├── manage.sh        # Установка и эксплуатация
├── .env             # Ваш файл с настройками
└── requirements.txt # Зависимости
```
