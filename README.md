# 🫁 Пикфлоуметр — Семейный бот

Telegram-бот для отслеживания пиковой скорости выдоха (ПСВ).
**1 ребёнок + 2 родителя** — все ID в `.env`, регистрация не нужна.

## Возможности

- 🤖 **Авто-регистрация** — бот знает своих по ID из `.env`
- 🕐 **Авто-утро/вечер** — определяется по времени (< 12 / ≥ 12)
- 📊 **Статус-блок** — в меню: сегодня, последний замер, тренд
- 📥 **Быстрый ввод** — нажал кнопку → ввёл число → готово
- ✏️ **Исправить последний** — опечатался? одна кнопка
- 📊 **Сводка** — все замеры дня (родители)
- 📈 **Неделя vs прошлая** — тренды утро/вечер
- 🏆 **Best/worst на графике** — аннотации
- 🔔 **Напоминания** — 10:00 / 22:00 если забыл замер
- 📋 **Недельный отчёт** — воскресенье 21:00
- 📲 **Уведомление родителю** — при каждом замере
- 🚨 **Красная зона** — мгновенное предупреждение

## Настройка (.env)

```env
BOT_TOKEN=8565342225:AAF...
CHILD_ID=123456789
PARENT_IDS=987654321,111222333
CHILD_NAME=Маша
TARGET_PEF=260
DB_PATH=peakflow.db
```

ID узнать через [@userinfobot](https://t.me/userinfobot).

## Запуск

```bash
cd /root/bot/picklo
source venv/bin/activate
python bot.py
```

## Тесты

python -m pytest test_bot.py -v
