## 📖 О проекте

Пикфлоуметрия — метод измерения пиковой скорости выдоха (ПСВ), используемый для мониторинга астмы и других заболеваний дыхательных путей. Этот бот помогает семье вести учёт показаний, отслеживать динамику и не пропускать замеры.

### ✨ Возможности

| Функция | Описание |
|---------|----------|
| 🤖 **Авто-регистрация** | Бот знает всех по ID из `.env` — без вопросов и привязок |
| 🕐 **Авто-утро/вечер** | Время суток определяется автоматически: `< 12:00` → 🌅, `≥ 12:00` → 🌆 |
| 📊 **Статус-блок** | В главном меню: замеры сегодня, последний результат, тренд |
| 📥 **Быстрый ввод** | Кнопка → число → готово. Минимум действий |
| ✏️ **Исправление** | Кнопка «✏️ Исправить последний» — без удаления и повторного ввода |
| 📈 **Сводка** | Все замеры дня + статистика утро/вечер (для родителей) |
| 📊 **Неделя vs прошлая** | Сравнение недель с трендами по утрам и вечерам |
| 🏆 **Best / Worst** | На графике — лучший и худший результаты |
| 🔔 **Напоминания** | 10:00 / 22:00 — если ребёнок забыл сделать замер |
| 📋 **Недельный отчёт** | Каждое воскресенье в 21:00 — полная сводка родителям |
| 📲 **Уведомления** | При каждом замере — второму родителю |
| 🚨 **Красная зона** | Мгновенное предупреждение при ПСВ < 60% от нормы |

## 🚀 Быстрый старт

### 1. Получите токен бота

Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → следуйте инструкциям → скопируйте токен.

### 2. Узнайте Telegram ID

Откройте [@userinfobot](https://t.me/userinfobot) → отправьте любое сообщение → скопируйте `Id`.

### 3. Настройте `.env`

```bash
cp .env.example .env
```

```env
BOT_TOKEN=123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxx
CHILD_ID=123456789
PARENT_IDS=987654321,111222333
CHILD_NAME=Маша
TARGET_PEF=260
DB_PATH=peakflow.db
```

### 4. Запустите

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## 🎨 Цветовые зоны

| Зона | Процент от нормы | Значение |
|:---:|:---:|----------|
| 🟢 | ≥ 80% | Хорошая компенсация |
| 🟡 | 60–79% | Внимание, ухудшение |
| 🔴 | < 60% | Опасно — свяжитесь с врачом |

---

## 🔔 Автоматические уведомления

| Событие | Когда | Кому |
|---------|-------|------|
| ⏰ Утренний замер пропущен | 10:00, если нет 🌅 | Оба родителя |
| ⏰ Вечерний замер пропущен | 22:00, если нет 🌆 | Оба родителя |
| 📋 Недельный отчёт | Вс 21:00 | Оба родителя |
| 🚨 Красная зона | Мгновенно | Оба родителя |
| 📝 Новый замер | Мгновенно | Другой родитель |

## ⚙️ Настройка

### Переменные окружения

| Переменная | Тип | Обяз. | По умолч. | Описание |
|-----------|-----|:---:|:---:|----------|
| `BOT_TOKEN` | string | ✅ | — | Токен бота от BotFather |
| `CHILD_ID` | int | ✅ | — | Telegram ID ребёнка |
| `PARENT_IDS` | string | ✅ | — | ID родителей через запятую |
| `CHILD_NAME` | string | ❌ | `Ребёнок` | Имя ребёнка |
| `TARGET_PEF` | int | ❌ | `260` | Целевая ПСВ от врача |
| `DB_PATH` | string | ❌ | `peakflow.db` | Путь к SQLite файлу |

### Константы (в `config.py`)

| Константа | Значение | Описание |
|-----------|:---:|----------|
| `ZONE_GREEN` | `80` | Порог зелёной зоны, % |
| `ZONE_YELLOW` | `60` | Порог жёлтой зоны, % |
| `REMINDER_MORNING_DEADLINE` | `10` | Дедлайн утреннего замера |
| `REMINDER_EVENING_DEADLINE` | `22` | Дедлайн вечернего замера |
| `WEEKLY_REPORT_DAY` | `6` | День отчёта (0=Пн, 6=Вс) |
| `WEEKLY_REPORT_HOUR` | `21` | Час отчёта |
