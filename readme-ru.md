## 📖 О проекте

Пикфлоуметрия — метод измерения пиковой скорости выдоха (ПСВ), используемый для
мониторинга астмы и других заболеваний дыхательных путей. Сервис помогает семье вести
учёт показаний, отслеживать динамику и не пропускать замеры: **бот** для быстрых
действий и уведомлений, **Telegram Mini App** для графиков, аналитики и настроек.

Сервис мульти-семейный: каждая семья изолирована (`family_id`), у семьи один или
несколько детей, у каждого родителя — свой активный ребёнок. Регистрация —
самопропускная: создать семью или войти по коду приглашения.

### ✨ Возможности

| Функция | Описание |
|---------|----------|
| 🏠 **Семьи и приглашения** | Создать семью или войти по коду (`/start`, deep-link) |

| ✏️ **Исправление** | «✏️ Исправить последний» — без удаления и повторного ввода |
| 📈 **Сводка и неделя** | Замеры дня со статистикой; сравнение недель по утрам и вечерам |
| 📊 **График (Mini App)** | Типы линия/столбцы/точки, диапазон неделя/месяц, тултип с заметкой, режим «Сравнить» |
| 🏅 **Геймификация** | Серия дней подряд; достижения 7/30/100 дней и 100/500/1000 замеров |

| 🔔 **Напоминания** | Ребёнку и родителям; часы настраиваются на семью |
| 📋 **Недельный отчёт** | Каждое воскресенье в 21:00, на каждого ребёнка |
| 📲 **Уведомления** | При каждом замере — родителям семьи |
| 🚨 **Красная зона** | Мгновенное предупреждение при ПСВ < 60% (кроме автора замера) |
| 📥 **Экспорт и бэкап** | CSV по периодам; бэкап данных одной семьи |
| 🩺 **Метрики** | Расширенный `/healthz` и опциональный `GET /metrics` (Prometheus) |

## 🚀 Быстрый старт

### 1. Получите токен бота

Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.

### 2. Узнайте Telegram ID

Откройте [@userinfobot](https://t.me/userinfobot) → отправьте сообщение → скопируйте `Id`.

### 3. Настройте `.env`

```bash
cp .env.example .env
```

```env
BOT_TOKEN=123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxx
CHILD_ID=123456789              # сид/fallback ребёнка семьи №1
PARENT_IDS=987654321,111222333  # сид/fallback родителей семьи №1
CHILD_NAME=Маша
TARGET_PEF=260
DB_PATH=peakflow.db
TZ_OFFSET=5

WEBAPP_HOST=127.0.0.1
WEBAPP_PORT=8080
WEBAPP_URL=
METRICS_ENABLED=0
METRICS_TOKEN=
```

> Прямые ID в `.env` нужны только для семьи №1 (сид миграции и fallback). Остальные
> семьи регистрируются в боте: «🏠 Создать семью» или «🔑 Войти по коду».

### 4. Запустите

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## 📱 Mini App

Когда задан `WEBAPP_URL`, бот добавляет кнопку «💨 Дневник». Вкладки:

- **Сегодня** — замеры дня, быстрый ввод с заметкой;
- **История** — постранично, правка/удаление (родителям);
- **График** — canvas без библиотек: типы линия/столбцы/точки, диапазон неделя/месяц,
  тултип (значение, %, зона, заметка), режим «Сравнить» (текущий vs прошлый период);
- **Статистика** — средние, тренд, 🔥 серия и сетка бейджей;
- **Аналитика** — зоны (pie), heatmap по дням недели, тренд за 14 дней, корреляция заметок;
- **⚙️ Настройки** (родителям) — целевая ПСВ, часы напоминаний, PDF-отчёт врачу,
  экспорт CSV, бэкап БД.

Доступ только у ребёнка и родителей: проверка подписи Telegram initData, данные старше
24 часов отклоняются. PWA: Mini App устанавливается на домашний экран, service worker
кэширует оболочку (данные API не кэшируются).

## ⚙️ Настройка

### Переменные окружения

| Переменная | Тип | Обяз. | По умолч. | Описание |
|-----------|-----|:---:|:---:|----------|
| `BOT_TOKEN` | string | ✅ | — | Токен бота от BotFather |
| `CHILD_ID` | int | ❌ | `0` | Telegram ID ребёнка семьи №1 (сид/fallback) |
| `PARENT_IDS` | string | ❌ | `0,0` | ID родителей семьи №1 через запятую (сид/fallback) |
| `CHILD_NAME` | string | ❌ | `Ребёнок` | Имя ребёнка семьи №1 |
| `TARGET_PEF` | int | ❌ | `260` | Целевая ПСВ по умолчанию |
| `DB_PATH` | string | ❌ | `peakflow.db` | Путь к SQLite файлу |
| `TZ_OFFSET` | int | ❌ | `5` | Часовой пояс (смещение от UTC) |
| `WEBAPP_HOST` | string | ❌ | `127.0.0.1` | Хост веб-сервера Mini App |
| `WEBAPP_PORT` | int | ❌ | `8080` | Порт (0 = выключить веб) |
| `WEBAPP_URL` | string | ❌ | — | Публичный HTTPS-URL Mini App |
| `METRICS_ENABLED` | bool | ❌ | `0` | `1` — включить `GET /metrics` |
| `METRICS_TOKEN` | string | ❌ | — | Bearer-токен для `/metrics` |

### Константы (в `config.py`)

| Константа | Значение | Описание |
|-----------|:---:|----------|
| `ZONE_GREEN` | `80` | Порог зелёной зоны, % |
| `ZONE_YELLOW` | `60` | Порог жёлтой зоны, %; красная — ниже |
| `WEEKLY_REPORT_DAY` | `6` | День отчёта (0=Пн, 6=Вс) |
| `WEEKLY_REPORT_HOUR` | `21` | Час отчёта |

> Часы напоминаний — на семью (правит родитель).
